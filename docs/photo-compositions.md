# 图片配文字构图

2026-11-06：依据照片叠字、留白分区、生活记录与杂志式信息层级整理 10 套原创构图。
它们是常见形式的实用归纳，并非小红书官方按使用量统计的前十名。

参考：
- [Canva：小红书笔记封面类型与设计要点](https://www.canva.cn/learn/xiaohongshu-note-cover/)
- [Canva：小红书爆款风向标模板库](https://www.canva.cn/zh_cn/work-kits/rednote-viral-templates/)
- [Canva：热门模板目录](https://www.canva.cn/popular-recommend/templates/)

本应用自行实现构图、示意图与文字样式，未复制或内置第三方模板、图片或付费素材。
照片由用户上传；缩略图仅以几何形状示意图片位置。

构图：全屏大字、底部压字、顶部留白、上图下文、左文右图、左图右文、拍立得留白、左上叠字、杂志边栏、半透明字卡。
各模板提供图框比例、正文与标题位置/宽度/对齐、字体和字号、配色及必要的遮罩。
套用时保留用户图片、裁剪位置、透明度、模糊度及画布尺寸。字体按当前画布尺寸缩放。
原十套纯文字模板继续保留，历史记录中的 ID 不变。
