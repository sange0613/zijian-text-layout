## 澹雅明体的 IPA 原始字体信息

澹雅明体是新愚公基于一点明体修改的字体，我们直接分发其未修改的 TTF。
一点明体的原始项目及完整历史版本：https://github.com/ichitenfont/I.Ming 。
IPA 原始字库及授权资料：https://moji.or.jp/ipafont/ 。
若希望使用原始字库，可移除本应用的澹雅明体 CSS 声明，在系统安装原始字库后选用原字库。
本目录保留 IPA 1.0 完整许可，接收者可依该许可继续复制、嵌入与分发。
